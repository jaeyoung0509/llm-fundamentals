# llm-fundamentals

고등학교 기본 수학 배경의 학습자도 따라올 수 있도록, 수학 기초부터 GPT-3 이해, PyTorch 실습, 강화학습, 최신 AI 엔지니어링 실무 패턴까지 연결하는 이중 언어(KO/EN) ebook 프로젝트다.

이 저장소는 VitePress 기반 문서 사이트를 사용하며, Mermaid 다이어그램과 풍부한 Markdown 기능을 활용해 "이해 -> 구현 -> 실무 적용" 흐름으로 내용을 구성한다.

## 빠른 시작

```bash
npm install
npm run docs:dev
```

배포용 빌드:

```bash
npm run docs:build
```

GitHub Pages 기준 배포 경로는 `https://jaeyoung0509.github.io/llm-fundamentals/`다.
