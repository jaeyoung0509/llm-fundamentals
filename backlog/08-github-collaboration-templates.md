## Summary

Create the minimum collaboration scaffolding for issue-driven work.

## Scope

- issue templates
- pull request template
- contributing guide
- label strategy

## Acceptance criteria

- [ ] Templates exist under `.github/`
- [ ] `CONTRIBUTING.md` defines branch and PR policy
- [ ] Labels are documented or created in the repository
- [ ] Branch hint: `feature/<issue>-github-collaboration-templates`
- [ ] PR target hint: `develop`
