# 수학 기초

## 이 장의 목표

- 함수와 로그, 지수를 모델 스케일 관점으로 읽는다.
- 벡터와 행렬을 "데이터와 파라미터를 담는 그릇"으로 이해한다.
- 미분을 변화율이 아니라 "손실을 줄이는 방향 신호"로 이해한다.
- 확률을 불확실성과 예측의 언어로 받아들인다.

## 최소 수학 실라버스

### 1. 함수, 로그, 지수

신경망에서는 값이 선형으로만 움직이지 않는다. softmax, cross-entropy, learning rate decay처럼 로그와 지수는 계속 등장한다.

### 2. 벡터와 행렬

- 벡터: 한 샘플의 특징 묶음
- 행렬: 여러 샘플 또는 가중치 묶음
- 행렬곱: 입력 특징과 가중치를 섞어 새로운 표현을 만드는 연산

### 3. 미분과 gradient

미분은 "조금 바꿨을 때 손실이 얼마나 달라지는가"를 측정한다. gradient descent는 이 정보를 이용해 파라미터를 반대 방향으로 움직이는 절차다.

```text
new_weight = old_weight - learning_rate * gradient
```

### 4. 확률과 기대값

모델은 정답을 확실히 아는 기계가 아니라, 가능한 답의 분포를 추정하는 기계다. 기대값은 평균적인 결과를, 분산은 흔들림의 정도를 보여준다.

## 꼭 연결해야 하는 것

| 수학 개념 | 모델에서의 역할 |
| --- | --- |
| 벡터 | 토큰, 임베딩, 특성 표현 |
| 행렬곱 | 선형 변환과 attention 계산 |
| 미분 | 역전파와 파라미터 업데이트 |
| 확률 | 로짓, softmax, 샘플링 |
