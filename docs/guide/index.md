## 논문 읽기용 수학 사다리

수학 장을 읽는 목적은 시험 문제를 푸는 것이 아니라, 아래 같은 문장을 겁먹지 않고 읽는 데 있다.

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k))V
L = -sum_t log p_theta(y_t | y_<t, x)
theta <- theta - eta * grad_theta L
```

처음에는 식 전체를 한 번에 이해하려 하지 말고, 아래 순서대로 쪼개서 읽는다.

1. 기호가 무엇을 뜻하는지 확인한다.
2. shape가 어떻게 흘러가는지 본다.
3. 어떤 연산이 점수 계산이고, 어떤 연산이 정규화인지 구분한다.
4. loss가 무엇을 벌주고 있는지 확인한다.
5. gradient가 어디로 전파될지 상상한다.

## 논문을 읽을 때 먼저 보는 5가지

- 기호 사전: `x`, `X`, `W`, `h`, `p`, `L`, `theta`가 각각 데이터인지 파라미터인지 출력인지 먼저 구분한다.
- shape 흐름: 벡터인지 행렬인지, `(batch, seq, dim)`인지 `(seq, seq)`인지 먼저 본다.
- 목표 함수: 모델이 최소화하는 값이 무엇인지 본다.
- 분포 해석: `softmax`, `log`, `expectation`이 붙으면 확률과 평균 관점으로 읽는다.
- 업데이트 규칙: `grad`, `optimize`, `backprop`가 나오면 학습 신호 관점으로 읽는다.
