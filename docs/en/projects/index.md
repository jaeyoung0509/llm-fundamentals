# Projects

## One Sentence to Keep

A strong project is not just runnable code. It also explains design choices, evaluation logic, and operational risk.

## Proposed Projects

1. a character-level or tiny tokenizer-based language model,
2. a document QA or mini RAG app,
3. a bandit or simple RL experiment.

## Project Template

- problem statement,
- data and constraints,
- model or system design,
- implementation,
- evaluation,
- retrospective.

## Checklist

- is the problem clearly stated,
- is there an evaluation criterion,
- can the retrospective name concrete improvements.

## How This Connects Forward

Projects close the first loop, then send the learner back into math, Transformers, and AI engineering for a deeper second pass.
